# گل‌آوا — Golava

**رادیوی اینترنتی** — گل‌ها، شعرخوان گنجور، داستان‌خوانی و مدیتیشن  
گل‌آوا یک رادیوی تحت وب با چهار بخش است: پخش تصادفی از آرشیو برنامهٔ گل‌ها (موسیقی اصیل ایرانی)، خوانش اشعار از گنجور، نثرخوانی از داستان‌های فارسی و صداهای آرامش‌بخش برای مدیتیشن.

## ✨ ویژگی‌ها

- **۴ حالت پخش:** گل‌ها (موسیقی)، گنجور (شعر)، نثرخوان (داستان)، مدیتیشن (آرامش)
- **لود تنبل داده‌ها:** شاعران بزرگ (مولانا، سعدی، حافظ و …) در پس‌زمینه لود می‌شوند — کاربر فوراً فهرست شاعران را می‌بیند
- **فهرست گروه‌بندی شده:** شاعران به بخش‌های شعری دسته‌بندی شده‌اند (غزلیات، مثنوی، رباعیات و …)
- **کشوی اطلاعات:** نمایش متن کامل شعر یا توضیحات
- **جستجو** در کل فهرست
- **تنظیمات:** تم (روشن/تاریک/طلوع/غروب)، قلم (۳ دسته)، ضخامت، اندازه، فاصله خطوط، رنگ متن
- **تایمر خواب:** ۱۵/۳۰/۴۵/۶۰ دقیقه
- **چت زنده:** پیام‌های شنوندگان از Firebase Realtime Database
- **پیشرفت خودکار:** توقف خودکار در انتهای فهرست، شافل، تکرار یک، تکرار فهرست

## 🚀 شروع

نیاز به سرور ندارد. فقط فایل‌ها را روی هر هاست استاتیک قرار دهید.

```bash
git clone <repo-url>
# فایل‌ها را روی GitHub Pages، Netlify، Vercel یا هر CDN استاتیک deploy کنید
```

### Firebase (اختیاری)

چت زنده نیاز به پروژهٔ Firebase دارد. فایل `chat.js` را باز کنید و `firebaseConfig` را با اطلاعات پروژهٔ خود پر کنید:

```js
const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "your-project.firebaseapp.com",
  databaseURL: "https://your-project-default-rtdb.firebaseio.com",
  // …
};
```

اگر Firebase تنظیم نشود، ویجت چت مخفی می‌ماند.

## 🔧 شخصی‌سازی

### افزودن شاعر جدید

۱. یک فایل `ganjoor-<poet>.js` با آرایه‌ای از اشعار و متغیر `GANJOOR_POEMS_<POET>` بسازید.  
۲. فایل `gen_index.js` را اجرا کنید تا `ganjoor-index.js` بازتولید شود.

### تم جدید

در `styles.css` یک بلوک `html[data-theme="…"]` اضافه کنید با متغیرهای CSS مورد نیاز.
